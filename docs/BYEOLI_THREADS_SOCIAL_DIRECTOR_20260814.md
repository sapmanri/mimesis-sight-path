# 별이 Threads Social Director 정본 — 2026-08-14

상태: **구현·로컬 검증 완료 / 공개 배포·실계정 영수증 확인 전**

이 문서는 `@byeoli_log`의 실제 Threads 운영 계약이다. 과거 BUILD 417·422·425에서 만든
08시·18시·22시 고정 발행, 댓글 숙성, 답글 비율, 사람 Draft/승인은 이 문서로 대체한다.

## 1. 왜 다시 만들었나

과거 구현은 “별이가 자유롭게 운영한다”고 부를 수 없었다.

- 루트 글은 하루 세 고정 시각에 외부 크론이 발행했다.
- 답글은 비율·숙성·계정/게시물 상한과 사람 승인 상태를 거쳤다.
- 댓글을 읽는 실행도 운영 화면 또는 주기 호출에 기대었다.
- 코드가 있어도 OAuth 권한·실계정·실제 발행 영수증까지 확인하지 않은 채 완료로 말할 여지가 있었다.

새 계약은 **코드 존재, 배포, 실계정 실행을 각각 다른 증거로 확인**한다.

## 2. 소유권 경계

- 쓰기 계정은 오직 `@byeoli_log`다.
- OAuth 장기 토큰을 저장하기 전에 `/me`의 ID와 username을 다시 확인한다.
- username이 `@byeoli_log`가 아니면 토큰을 저장하지 않는다.
- `@byeol.toon`은 다른 사람이 별이를 소재로 운영하는 외부 계정이다. Crawl4AI로 읽을 수는
  있지만 이 실행선에는 그 계정으로 게시·댓글·답글을 쓰는 기능이 없다.
- `@byeol.toon`의 공개 글에 댓글을 남길 때도 글 작성자는 오직 `@byeoli_log`다.
- 외부 댓글 대상은 Crawl4AI가 실제 읽은 permalink와 Meta `profile_posts`의 실제 permalink·
  username·글 ID가 모두 일치한 공개 루트 글만 허용한다. 링크 일부나 추측 ID로 쓰지 않는다.
- 자기 댓글 대상은 Meta가 반환한 `@byeoli_log`의 `is_reply=false` 루트 글 ID만 허용한다.

## 3. 별이가 고르는 세 행동

한 번 깨어날 때 별이가 자료와 자기 최근 글을 보고 행동을 고른다.

1. `post` — `@byeoli_log`에 새 루트 글을 쓴다.
2. `comment` — 자기 루트 글 또는 읽고 Meta ID까지 확인한 외부 공개 글을 골라,
   `@byeoli_log` 이름으로 그 아래에 댓글을 단다.
3. `silence` — 아무것도 쓰지 않는다.

별도로, 자기 글에 다른 사람이 남긴 모든 단계의 댓글은 하나씩 읽고 다음을 고른다.

- 답글을 작성해 즉시 공개한다.
- 답하지 않고 지나간다.
- 혼자 기억할 가치가 있으면 북마크 영수증을 남긴다.

사람이 초안을 승인·거절하거나 발행 시각을 정하는 상태는 없다.

## 4. 무엇이 별이를 깨우나

고정 게시 시간표와 주기 댓글 폴러는 없다. 아래의 실제 사건만 Social Director를 깨운다.

- 새 방송 편성 등록
- 사연의 실제 송출 확인
- Crawl4AI 또는 공개 API 관찰 결과 도착
- 자기 Threads·YouTube 선반 갱신
- 별이가 직전 판단에서 직접 고른 다음 한 번의 확인 시점
- 별이가 다음 확인을 고르지 않았을 때만 무기한 휴면을 막는 12시간 생존 확인
- 운영자가 최초 가동 또는 장애 확인을 위해 명시적으로 한 번 시작한 경우

Meta Threads 공식 API에서 댓글 Webhook이 확인되지 않았기 때문에 “새 댓글 즉시 깨우기”라고
과장하지 않는다. 새 댓글은 위 실제 사건, 별이가 고른 다음 확인, 또는 최대 12시간의 생존 확인 때
수집된다. 12시간 생존 확인은 게시 시간표도 수량 장치도 아니다. 판단 기회만 열고 별이는 다시
`post`·`comment`·`silence` 중 하나와 다음 확인 여부를 직접 고른다. 이를 숨기기 위한 15분 댓글
폴러는 두지 않는다.

## 5. 없앤 제한과 남긴 기계 책임

없앴다:

- 08시·18시·22시 발행 슬롯
- 하루 게시 수량 목표
- 답글 비율과 일/계정/게시물별 답글 상한
- 댓글 숙성 시간과 카테고리별 기계 차단
- 사람 Draft/approve/reject/bookmark 조작 API
- 운영 화면을 열 때 강제로 댓글을 수집하는 `?force=1` 경로

남긴 것은 취향 제한이 아니라 외부 사고 방지와 실행 무결성이다.

- 같은 사건·댓글 중복 처리 방지
- 최근 글과 완전히 같은 문장 재발행 방지
- URL·이메일·전화번호 재노출 방지
- Threads의 500자 플랫폼 한도
- OAuth 계정 불일치 시 fail-closed
- 불명확한 Meta 발행 실패를 자동으로 중복 재발행하지 않고 실패 영수증으로 남김
- 실행 장애일 때만 기술 재시도. 이것은 별이의 편집 시간표가 아니다.
- `nextLookInMinutes=null` 뒤에도 감독 자체가 영구 소실되지 않게 하는 12시간 생존 확인.
  이 확인은 글·댓글을 강제하지 않으며 `silence`를 정상 성공으로 기록한다.

## 6. 실행선

```text
방송·관찰 사건 / 별이가 고른 한 번의 alarm / 무기한 휴면 방지 생존 alarm
  -> ByeoliSocialDirector Durable Object
  -> /api/radio/social-agent
     -> @byeoli_log 계정·글 선반 확인
     -> Crawl4AI로 읽은 외부 Threads 링크와 Meta 실제 ID 교차 확인
     -> 자기 글의 전체 댓글 수집
     -> 댓글마다 답글/무응답/기억 판단과 즉시 실행
     -> 관찰·방송·사연·편성 후보에서 post/comment/silence 판단과 즉시 실행
     -> 실행 영수증 저장
     -> 별이가 원할 때만 다음 한 번의 alarm
```

별이의 자유 판단과 별개로, 사용자가 유지하기로 한 미디어 예약선 두 개만 동작한다.

- `/api/autopost`: 08·18·22 KST에 2D Walk/관측소 스크린샷을 발행한다. 명시 슬롯 검증과
  성공 영수증으로 재시도 중복을 막고, Social Director는 깨우지 않는다.
- `/api/sketch-daily`: 밤 그림 3장 판정이 끝나면 추천 1장을 자동 채택·발행한다. 이미 사람이
  채택한 그림은 덮지 않고, 날짜별 성공 영수증으로 하루 1장만 허용한다.

## 7. 증거 계약

완료 보고는 아래가 모두 있어야 한다.

1. 로컬: 자율성·계정 경계·예약 미디어 슬롯/하루 1장 테스트와 전체 빌드가 exit 0.
2. 배포: Social Director Worker, Pages Functions, 두 서비스 바인딩이 현재 커밋으로 배포됨.
3. 공개 경계: 무인증 `/api/autopost` 401, 무인증 agent/director 403, Worker health 200.
4. 실계정: `/me`가 `@byeoli_log`임을 확인하고 댓글 읽기 권한 성공.
5. 실실행: 한 번의 감독 실행에서 post/comment/silence 판단과 댓글 답글 영수증을 확보.
   - 별이가 `silence`를 골랐다면 게시물이 없는 것이 정상이다. 이 경우에도 판단 이유와 실행 ID가 있어야 한다.
   - 실제 댓글이 없으면 답글 0건은 기능 실패 증거가 아니다. 댓글 수집 성공 영수증과 0건을 함께 보고한다.
   - 권한이 부족하면 완료가 아니라 OAuth 재승인 필요 상태로 보고한다.

## 8. 운영 키와 영수증

- `radio:social-agent:state:v1` — 마지막 실행
- `radio:social-agent:receipts:v1` — 최근 실행 영수증
- `reply_log` — 댓글별 수집·별이 판단·실제 답글 결과
- `reply_ingest_meta` — 마지막 댓글 수집 시각·오류
- `publish_log` — 루트 글/자기 댓글/침묵/실패 감사 기록
- Durable Object state — 마지막 깨움·완료·다음 한 번의 확인·기술 오류

토큰, 앱 비밀키, 댓글 작성자의 username 원문, IP, UA는 영수증에 저장하지 않는다.
